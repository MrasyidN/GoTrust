# Go-Trust – AI-Powered Order Verificator

Go-Trust is an AI-powered multi-layer detection system designed to secure order transactions, particularly in digital food delivery services like GoFood. It helps identify and prevent fraudulent orders by combining real-time analytics, user behavior analysis, geospatial intelligence, and AI-driven risk scoring.

---

## 🚨 Problem Statement

The rise of fake (fiktif) orders made by irresponsible users is a growing concern in online food delivery platforms. These malicious activities result in:

- **Merchants** losing ingredients, time, and operational resources.
- **Drivers** wasting fuel, time, and money for non-existent deliveries.
- **Platform providers** facing increased costs for customer service, refund processing, and reputation damage.

---

## 🔍 Root Cause Analysis

Fraudulent transactions persist due to:

- **Limited Context Awareness** – Lack of geographic and time-based checks.
- **Insufficient User Behavior Analytics** – No deep profiling of user patterns.
- **Lack of Real-time Verification** – Current systems only respond after complaints.
- **Weak Identity Verification** – Users can easily bypass the system by creating new accounts.

---

## 💡 Our Solution – Go-Trust

An intelligent **Multi-Layer Detection System** built with AI to proactively verify and safeguard transactions.

### Key Capabilities:

- Real-time risk scoring
- Adaptive verification
- Multi-dimensional data analysis
- Automated response engine

## 📊 Data Indicators Used

To ensure accurate analysis, the system leverages:

- **User Behavioral Patterns**
- **Transaction and Order Analytics**
- **Device and Technical Fingerprinting**
- **Geospatial and Temporal Intelligence**

---

## 🧮 Risk Scoring Formula

The system calculates a **Risk Score** based on weighted indicators:

- `0.30` × Behavioral Anomaly  
- `0.25` × Transaction Pattern  
- `0.20` × Geospatial Risk  
- `0.15` × Device Trust  
- `0.10` × Network Analysis

---

## 🤖 Automated Response System

| Risk Score Range | Action Taken |
|------------------|--------------|
| 90–100           | Auto-cancel order + alert triggered |
| 70–89            | Verification required (dynamic methods) |
| 50–69            | Enhanced monitoring |
| Below 50         | Normal order processing |

### Dynamic Verification Methods

- 📞 Phone Call with PIN confirmation  
- 📩 SMS OTP  
- 🧬 Biometric Verification (face/fingerprint)  
- 🌐 Social Account Linking  
- 📍 GPS Location Ping
